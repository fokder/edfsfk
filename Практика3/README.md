# Практична №3 — Графічний редактор

Окремий проєкт за першим прикладом практичної №3 (сторінки 11–16 методички)
із виконанням усіх п’яти пунктів «Завдання до Практичної №3».
Телефонний довідник із практичної №2 залишається окремим проєктом.

## Запуск

Відкрийте `Практика3.sln` у Visual Studio на Windows.
Потрібні компонент «Розробка класичних програм .NET» та targeting pack
.NET Framework 4.7.2. Зберіть рішення та натисніть F5.
`Form1.cs` — логіка, `Form1.Designer.cs` — розташування елементів і події,
`Program.cs` — запуск. Форму можна редагувати в конструкторі Visual Studio.
`Form1.resx` — файл ресурсів форми, пов’язаний із `Form1.cs` у проєкті.

Щоб побачити **Form1.cs [Design]**, відкрийте `Практика3.sln`,
у Провіднику рішень виберіть `Form1.cs` і натисніть **Shift+F7**
або правою кнопкою → **Переглянути конструктор**.
Відкривати `Form1.Designer.cs` для цього не потрібно: він показує код розмітки.
Поля параметрів фігур спочатку приховано відповідно до методички;
під час запуску вони з’являються після вибору фігури.

## Відповідність завданню

1. Кнопка «Колір» відкриває `ColorDialog`. Вибраний колір застосовується до
   кисті, контурів фігур, заливки й тексту.
2. У списку фігур є прямокутник, а також лінія, трикутник та еліпс.
3. Біля тексту є два поля координат X та Y.
4. Кнопка «Шрифт» відкриває `FontDialog`.
5. Кнопка «Зберегти» відкриває `SaveFileDialog` і записує рисунок у PNG.

Додатково реалізовано відкривання зображень через `OpenFileDialog`,
оскільки це зазначено в загальній меті роботи. Зображення масштабується
до розміру полотна, замінюючи його вміст. Очищення та відкривання замінюють
рисунок без підтвердження: спочатку збережіть потрібний результат.

## Користування

- Кисть: затисніть ліву кнопку миші на білому полі й рухайте мишею.
  Поле «Товщина кисті» також задає товщину контурів фігур.
- Фігура: виберіть тип, задайте параметри та натисніть «Малювати».
  Для лінії: X1, Y1, X2, Y2. Для трикутника: X1, Y1, X2, Y2, X3, Y3.
  Для еліпса та прямокутника: X, Y лівого верхнього кута, ширина та висота.
- «Заливка» доступна для еліпса й прямокутника.
- Текст: уведіть текст, задайте X і Y, виберіть шрифт і натисніть «Додати текст».
- «Очистити» робить полотно білим.
- Полотно має розмір 760 × 620. Початок координат — верхній лівий кут;
  X збільшується вправо, Y — вниз. Частини за межами полотна не видно.

## Як пояснити код

`canvas` — зображення Bitmap, яке зберігає всі намальовані елементи.
`pictureBox1.Image` показує його у вікні. На відміну від `CreateGraphics`
у першому прикладі методички, `Graphics.FromImage(canvas)` змінює саме
зображення, тому малюнок не зникає після перекриття вікна та потрапляє у файл.
Цей підхід також показано в другому прикладі методички.

`drawing` показує, чи затиснуто ліву кнопку. `previousPoint` зберігає попередню
точку миші. Подія MouseMove з’єднує її з новою точкою відрізком.
`Pen` задає колір і товщину лінії, `Brush` — колір заливки та тексту.
`using` звільняє ресурси малювання після виконання команд.
`Invalidate()` просить PictureBox перемалювати зображення на екрані.

Фігури малюються простими викликами DrawLine, DrawPolygon, DrawEllipse та
DrawRectangle. Для заливки використовуються FillEllipse і FillRectangle.
Координати спочатку перевіряються через int.TryParse, щоб помилка введення
не завершувала програму. Усі обробники розташовано в `Form1.cs`.

## Перевірка у Visual Studio

У цьому хмарному середовищі немає C#/.NET Framework та Windows Forms:
збірка і запуск графічного інтерфейсу не виконані.

Після збірки перевірте:

1. Кожну з чотирьох фігур, а також заливку еліпса й прямокутника.
2. Інший колір, товщину кисті, один клік та безперервний штрих мишею.
3. Текст у двох різних координатах, різні шрифти та розміри.
4. Збереження PNG, його відкривання та наявність фігур, штрихів і тексту.
5. Згортання й відновлення вікна: малюнок має залишитися.
6. Очищення та збереження порожнього полотна.
7. Нечислові координати, від’ємні числа й нульову ширину фігури:
   має з’явитися повідомлення, а програма має продовжити роботу.
8. Скасування кожного діалогу та відкривання пошкодженого файла.
