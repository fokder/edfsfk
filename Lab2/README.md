# Практична робота №2 — Телефонний довідник

## Запуск у Windows

Потрібна Visual Studio 2022 (версія 17.8 або новіша), компонент **«Розробка класичних програм .NET»** та .NET 8 SDK.

1. Відкрийте `Lab2.csproj` у Visual Studio.
2. Натисніть **F5**.

Або в терміналі Windows у папці проєкту: `dotnet run`.
WinForms працює лише у Windows. Усі елементи форми створюються кодом, тому файлу Designer немає.

## Як користуватися

- **Новий** очищає поля для нового контакту. Введіть дані й натисніть **Зберегти запис**. Прізвище обов'язкове.
- Виберіть контакт у списку, змініть поля та натисніть **Зберегти запис** для редагування.
- **Стерти** видаляє вибраний контакт із довідника та списку й очищає поля.
- У нижньому полі введіть повне прізвище та натисніть **Знайти**. Регістр не має значення. Якщо прізвище повторюється, знаходиться перший запис.
- Чотири кнопки переміщують між записами. Подвійне натискання рядка таблиці відкриває його на вкладці редагування.
- Меню сортує список і таблицю за прізвищем у двох напрямках.
- **Файл → Відкрити** дозволяє завантажити приклад `contacts.txt`.
- **Зберегти запис** змінює список у пам'яті; **Файл → Зберегти** записує весь список на диск.
- Перед закриттям або відкриттям іншого файлу програма пропонує зберегти зміни списку. «Скасувати» залишає програму відкритою. Після введення полів спочатку натискайте **Зберегти запис**: незастосований текст не входить у список.

## Що пояснити викладачу

1. `Contact` зберігає чотири рядки: прізвище, ім'я, телефон і адресу. Телефон є рядком, щоб не втрачати початковий нуль або знак `+`.
2. `List<Contact> contacts` — довідник у пам'яті. Окрема база даних не потрібна.
3. `TabControl` містить таблицю на першій вкладці та поля редагування на другій. `ComboBox.SelectedIndex` відповідає індексу контакту.
4. `RefreshList` заново заповнює таблицю і комбінований список з `contacts`, щоб вони показували однакові записи.
5. `SaveContact` додає контакт, коли немає вибраного запису, або замінює вибраний. `DeleteContact` видаляє його за індексом.
6. `FindIndex` знаходить перший збіг прізвища. `Sort` порівнює прізвища, а для зворотного порядку міняються місцями аргументи порівняння.
7. Файл має формат UTF-8: один контакт на рядок, чотири поля розділено табуляцією. Порядок: прізвище, ім'я, телефон, адреса. `Split` читає поля, `Join` об'єднує їх при збереженні.
8. `changed` позначає незбережені зміни списку. `ConfirmSave` обробляє «Так», «Ні» та «Скасувати»; скасування діалогу запису також не дозволяє закрити програму.
9. `try/catch` показує зрозуміле повідомлення при помилці файлу. Новий файл спочатку перевіряється повністю, тому помилка не стирає поточний довідник.
10. `MaxLength` обмежує довжину полів: 20, 20, 15 і 100 символів. Табуляції та переноси в полях заборонені, бо вони є роздільниками файлу.

## Ручна перевірка у Windows

1. Відкрити `contacts.txt`: у таблиці та списку мають бути три контакти.
2. Знайти `коваль`: має відобразитися Іван. Знайти відсутнє прізвище: має з'явитися повідомлення.
3. Створити контакт, змінити телефон, перевірити навігацію та сортування в обох напрямках.
4. Стерти контакт: запис має зникнути з обох списків, а поля — очиститися.
5. Зберегти файл, відкрити його знову й перевірити дані та українські літери.
6. Змінити запис і закрити вікно: перевірити «Скасувати», «Так» і скасування діалогу збереження.
7. Відкрити файл неправильного формату: має з'явитися помилка, поточні записи мають залишитися.
