# Практична №3 — два приклади з методички

Відкрийте `Практика3.sln` у Visual Studio на Windows із компонентом
«.NET desktop development» та .NET Framework 4.7.2 Targeting Pack.
Збережіть усі файли (Ctrl+Shift+S), зберіть рішення (Ctrl+Shift+B), запустіть F5.

## Form1 — перший проєкт, рисунок 2

Поле малювання розташоване ліворуч, елементи керування — праворуч,
у порядку з рисунка 2 методички: comboBox1, button1, checkBox1,
textBox1–textBox6, товщина кисті, button3, textBox7, button4, button2.
Координати фігури й checkBox1 спочатку приховано, button1 вимкнено —
відповідно до пункту 5. Після вибору фігури з’являються потрібні поля.

Збережено назви з прикладу: Drow, Graf, GC, textBox1–textBox7,
button1–button4 та обробники Load, SelectedIndexChanged, MouseMove,
MouseDown, MouseUp, Click. Заголовок Painting і підписи Paint, Clear,
Color, Text задаються у Form1_Load, як у пункті 11.

Малювання відповідає першому прикладу:

- Line — DrawLine, чотири значення: X1, Y1, X2, Y2.
- Triangle — три виклики DrawLine. Порядок шести значень **саме з методички**:
  X1, X2, X3, Y1, Y2, Y3.
- Ellipse — DrawEllipse або FillEllipse, чотири значення: X, Y, ширина, висота.
- Кисть — FillEllipse у MouseMove, розмір із numericUpDown1.
- Текст — DrawString із textBox7; колір LimeGreen з прикладу.
- Clear — Graphics.Clear(SystemColors.Window).

П’ять завдань на допрацювання виконано так:

1. Color (button3) відкриває ColorDialog і змінює колір кисті.
2. Rectangle у списку малює DrawRectangle / FillRectangle за тими самими
   параметрами, що й еліпс. Заливка відкриває ColorDialog, як у прикладі.
3. textBox8 і textBox9 під основними кнопками задають X і Y тексту.
4. «Шрифт» (button5) відкриває FontDialog; DrawString використовує вибраний шрифт.
5. «Зберегти рисунок» (button6) зберігає PNG через SaveFileDialog.

Окрема кнопка «Відкрити Form2» відкриває другий приклад.

### Необхідні відмінності від надрукованого коду

У першому прикладі Graphics створюється через CreateGraphics(). Такий рисунок
не зберігається в PictureBox.Image і зникає після перемальовування вікна.
Щоб виконати завдання зі збереження, додано Bitmap bmp_for_draw та
Graphics.FromImage(bmp_for_draw) — підхід із **другого прикладу тієї ж методички**.
Після малювання Invalidate оновлює PictureBox. Самі команди малювання залишено
з першого прикладу, без окремих моделей фігур і допоміжних масивів полів.

using звільняє Graphics, Brush та діалоги. Перевірка чисел і розмірів показує
повідомлення замість аварійного завершення. Малювання починається лише лівою
кнопкою миші й припиняється після її відпускання або втрати захоплення миші.

## Form2 — другий проєкт, рисунок 5 та надане фото

Окрема форма з полем малювання вгорі та трьома кнопками внизу:
**Відкрити**, **Зберегти**, **Очистити**. Відкривається кнопкою з Form1.
Кожне відкриття Form2 починається з порожнього полотна; потрібний результат
слід зберегти перед закриттям. Полотна двох форм незалежні.

Збережено змінні bmp_for_draw, start_point, Draw, pen_for_draw,
заокруглені кінці пера, DrawLine у MouseMove, діалоги відкривання та збереження.
Відкритий файл копіюється на полотно розміру PictureBox: зображення не блокується
на диску, а координати миші збігаються з координатами малювання.
Очищення змінює Bitmap, тому очищений рисунок також можна зберегти.
Формат збереження відповідає пункту діалогу (BMP, JPG, GIF або PNG), а не завжди
JPEG, як у надрукованому прикладі. Невикористаний full_name_of_image не потрібний.
Відкривання та очищення замінюють рисунок без підтвердження.

## Конструктор Visual Studio

У Провіднику рішень виберіть Form1.cs або Form2.cs:

- F7 — код.
- Shift+F7 — вкладка [Design].

Form1.Designer.cs / Form2.Designer.cs містять елементи та підключення подій,
.resx — стандартні файли ресурсів. Обидві форми підключені до .csproj.
Код не використовує Culture або System.Globalization.

## Перевірка

У хмарному середовищі перевірено XML проєкту/ресурсів, наявність файлів,
оголошення елементів та підключення обробників подій. Компілятора C# і Windows
Forms тут немає: збірка, запуск та відкривання конструктора **не перевірені**.

Перевірте на Windows після збірки:

1. Відкривання обох форм у конструкторі, підписи та розташування елементів.
2. У Form1 — кожну фігуру, прямокутник, заливки, зміну кольору кисті,
   товщини, координат тексту та шрифту.
3. Збереження всіх елементів у PNG і збереження після очищення.
4. У Form2 — відкривання зображення, малювання на ньому, збереження в кожному
   форматі, повторне відкривання результату та очищення.
5. Неправильні координати й скасування діалогів мають залишати програму робочою.
