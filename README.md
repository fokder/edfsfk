# Телефонний довідник

Навчальна програма C# Windows Forms для .NET Framework 4.7.2.
Відкрийте `Практика2.sln` у Visual Studio на Windows із компонентом
«Розробка класичних програм .NET» та targeting pack .NET Framework 4.7.2.
Виконайте Build → Rebuild Solution, потім F5. Файли `.exe` у репозиторії
належать попередній версії: для перевірки змін потрібно зібрати проєкт.

## Як користуватися

1. Виберіть «Редагувати → Новий запис», заповніть чотири поля.
2. Натисніть «Редагувати → Додати / зберегти запис» — запис потрапить до таблиці.
3. Для редагування виберіть прізвище зі списку, змініть поля та виконайте ту саму команду.
4. «Знайти» шукає перший точний збіг прізвища без урахування регістру.
   «Попередній» і «Наступний» переміщують вибір між записами.
5. «Видалити» видаляє вибраний запис. Сортування доступне в меню «Редагувати».
6. «Файл → Записати у файл» зберігає таблицю, «Прочитати з файла» відкриває її.

Важливо: редагування в полях спочатку потрібно підтвердити командою
«Додати / зберегти запис». Команда запису у файл зберігає саме таблицю.
Прізвища можуть повторюватися; список і навігація дозволяють вибрати кожен запис.

## Як пояснити код викладачу

- `dataGridView1` містить записи. Окремий масив на 100 осіб не потрібен.
- `fields` — чотири поля введення в порядку «прізвище, ім’я, телефон, адреса».
  Завдяки цьому один цикл замінює чотири майже однакові команди.
- `comboBox1.SelectedIndex` — номер вибраного рядка таблиці.
  Значення `-1` означає, що готується новий запис.
- `ShowRecord` переносить вибраний рядок у поля; `UpdateList` оновлює список прізвищ.
- Обробник «Додати / зберегти запис» перевіряє поля, додає новий рядок
  або змінює вибраний. `ValidField` перевіряє непорожнє значення та довжину.
- `GetRecords` копіює таблицю в тимчасовий список для запису у файл або сортування.
- `CompareSurnames` порівнює прізвища за позиціями літер у рядку українського
  алфавіту, без урахування регістру та незалежно від налаштувань Windows.
  Інші символи йдуть після українських літер за кодом символу.
  `SortTable` застосовує це порівняння; для зворотного порядку
  перевертає список. Потім показує впорядковані рядки в таблиці.
- `SaveData` відкриває стандартний діалог і записує рядки у файл.
  Читання спочатку перевіряє весь файл і лише потім замінює таблицю.
- `changesMade` запам’ятовує, що таблицю змінено. `ConfirmChanges` пропонує
  зберегти її перед відкриванням іншого файла або виходом.
- `using` закриває діалоги після використання; `try/catch` показує повідомлення
  про помилки файлів замість аварійного завершення.
- `Form1.Designer.cs` описує вигляд вікна, `Form1.cs` — його поведінку.
  `Form2` — вікно «Про програму», `Program.Main` запускає головне вікно.

Формат файла: один запис у рядку; поля розділені символом табуляції.
Порядок: прізвище, ім’я, телефон, адреса. Ліміти: 20, 20, 15, 100 символів.
Табуляції та переноси рядків усередині полів заборонено, щоб не пошкодити формат.

## Ручна перевірка після збірки

- Додайте двох людей з однаковим прізвищем і одного з іншим; перевірте список,
  пошук, обидві кнопки навігації та редагування саме вибраної людини.
- Перевірте сортування в обох напрямках, видалення середнього та останнього запису.
- Збережіть довідник, закрийте й відкрийте файл; порівняйте всі поля й порядок.
- Спробуйте порожні поля, граничні довжини та файл із неправильними даними.
  Невдале читання має залишати попередню таблицю.
- Змініть таблицю й перевірте «Так», «Ні», «Скасувати» під час виходу,
  а також скасування діалогу збереження.

У хмарному середовищі компілятор C# і Windows Forms відсутні,
тому збірка та перевірка графічного інтерфейсу тут не виконані.
