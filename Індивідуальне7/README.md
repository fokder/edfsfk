# Індивідуальне завдання — варіант 7

**Магазин кондитерських виробів. За типом вивести назву і ціну.**

## Що виконано

- Product — структура з п’ятьма полями: Name (назва), Type (тип),
  Price (ціна в гривнях), Weight (маса в грамах), Manufacturer (виробник).
- products — масив із десяти початкових записів. Ціни навчальні.
- Усі записи відразу показуються в таблиці.
- Пошук за типом показує назви та ціни всіх відповідних виробів.
- Кнопка збереження записує весь масив із п’ятьма полями у текстовий файл.
- Кнопка додавання дозволяє збільшувати кількість записів.

Одна форма, звичайна структура, масив і цикли. Без бази даних,
LINQ, окремих бібліотек чи встановлення пакетів.

## Відкривання

1. Відкрийте `Індивідуальне7.sln` із головної папки репозиторію.
2. Потрібні Visual Studio на Windows, компонент .NET desktop development
   і .NET Framework 4.7.2 Targeting Pack.
3. Ctrl+Shift+B — збірка, F5 — запуск.
4. У Провіднику рішень виберіть Form1.cs:
   F7 — код, Shift+F7 — конструктор форми.

Зберігайте всю папку проєкту разом із файлом рішення.

## Користування

У верхній таблиці показано всі вироби. Праворуч уведіть тип, наприклад
`Торт`, `Печиво`, `Цукерки` або `Тістечко`, та натисніть «Знайти».
Пошук точний, але не враховує регістр літер і зовнішні пробіли:
`торт` і `Торт` дадуть однаковий результат, `Торти` — інший тип.

Для додавання заповніть назву, тип, ціну, масу та виробника.
Натисніть «Додати запис» — рядок з’явиться в таблиці.
Ціна має бути не меншою за 0,01 грн, маса — не меншою за 1 г.
Після додавання результати попереднього пошуку очищаються: пошук можна повторити.

«Зберегти все у файл» записує **всі** товари, незалежно від пошуку.
Поля розділено табуляцією, перший рядок містить заголовки.
Збереження виконується вручну. Після закриття програми нові записи
залишаться лише в збереженому файлі; під час наступного запуску
знову завантажаться десять записів із коду. Читання файла завдання не вимагає.

## Пояснення для викладача

1. `struct Product` описує один виріб. Кожне поле зберігає окрему характеристику.
   decimal використано для ціни, int — для маси, string — для тексту.
2. `Product[] products` зберігає масив таких виробів. `products.Length` — їх кількість.
3. Конструктор викликає InitializeComponent для створення форми,
   а ShowProducts — для показу масиву в таблиці.
4. ShowProducts очищає таблицю та циклом for додає кожен елемент масиву.
5. buttonSearch_Click порівнює введений тип із полем Type кожного виробу.
   Якщо тип збігається, назва та ціна додаються до listBox1.
   StringComparison.OrdinalIgnoreCase дозволяє ігнорувати регістр літер.
6. buttonAdd_Click створює один Product із введених значень.
   Array.Resize збільшує масив на один елемент; новий запис займає останню позицію.
7. buttonSave_Click відкриває SaveFileDialog, а StreamWriter записує рядки у файл.
   Цикл проходить усі елементи масиву. using закриває файл після запису.
   try/catch показує повідомлення, якщо записати файл не вдалося.
8. Form1.Designer.cs описує кнопки, таблицю, поля та підключення Click.
   Form1.cs містить поведінку програми; Program.cs запускає Form1.

## Перевірка

У хмарному середовищі перевірено структуру проєкту, XML ресурсів,
підключення подій, п’ять полів структури та десять початкових записів.
Компілятора C# і Windows Forms тут немає: збірку й запуск не виконано.

Після збірки на Windows перевірте:

- На початку в таблиці 10 записів. «Торт» має показати Медовик — 450,
  Наполеон — 480, Шоколадний — 520 грн.
- «Печиво» дає 3 результати, «Цукерки» та «Тістечко» — по 2.
- ` тОрТ ` знаходить ті самі торти. Невідомий тип показує повідомлення
  в результатах; порожній запит викликає повідомлення у вікні.
- Додайте новий виріб: кількість стає 11; пошук знаходить його за типом.
- Збережіть файл: заголовок і всі 11 записів, у кожному п’ять полів.
- Перевірте скасування діалогу та додавання з порожніми текстовими полями.
