# Варіант 13 — Автотранспортне підприємство

Одна форма Windows Forms, звичайна структура, масив і цикли.
Без бази даних, LINQ та сторонніх пакетів.

## Відповідність завданню

- Структура Car має сім полів: Brand (марка), Plate (номерний знак),
  Driver (прізвище водія), Capacity (вантажопідйомність у тоннах),
  InTrip (чи в рейсі), DepartureDate (дата виїзду), DurationDays (тривалість у днях).
- Масив cars містить десять початкових навчальних записів.
- Увесь масив показується в таблиці та записується у текстовий файл.
- Пошук показує вільні автомобілі з достатньою вантажопідйомністю.
- Нові записи додаються через форму, тому кількість автомобілів можна збільшувати.

## Запуск

Відкрийте `Індивідуальне13.sln` у головній папці репозиторію.
Потрібні Visual Studio на Windows із .NET desktop development
та .NET Framework 4.7.2 Targeting Pack.

Ctrl+Shift+B — збірка, F5 — запуск.
У Провіднику рішень виберіть Form1.cs:
F7 — код, Shift+F7 — конструктор форми.
Зберігайте всю папку проєкту разом із файлом рішення.

## Користування

1. У таблиці зверху видно всі автомобілі та їхні характеристики.
2. Уведіть масу вантажу **в тоннах** праворуч і натисніть «Знайти».
   Наприклад, для 3,5 т початкові дані дають п’ять автомобілів:
   Iveco Daily, MAN TGL, Volvo FL, Isuzu NPR і Hyundai HD78.
3. Для нового автомобіля заповніть марку, номер, водія та вантажопідйомність.
   Номерний знак не повинен повторюватися. Текстові поля не можуть бути порожніми.
4. Якщо автомобіль зайнятий, увімкніть «Автомобіль у рейсі» й укажіть дату
   виїзду та тривалість. Для вільного автомобіля ці поля вимкнені й у таблиці
   показано тире. Після заповнення натисніть «Додати автомобіль».
5. «Зберегти все у файл» записує всі сім полів усіх автомобілів незалежно
   від результатів пошуку. Формат — текст UTF-8, поля розділено табуляцією.

Зайнятість визначається полем InTrip. Програма не обчислює завершення рейсу
за датою автоматично: так простіше виконати й пояснити поставлене завдання.
Пошук включає машину, вантажопідйомність якої точно дорівнює масі вантажу.
Після додавання старі результати пошуку очищаються; натисніть «Знайти» знову.

Збереження виконується вручну. Додані автомобілі залишаються в пам’яті
до закриття програми й у записаному файлі. Після нового запуску знову
показуються десять записів із коду. Читання з файла завдання не вимагає.

## Як пояснити код викладачу

- struct Car описує один автомобіль; кожне поле містить одну характеристику.
- string використано для тексту, decimal — для вантажопідйомності,
  bool — для стану «так/ні», DateTime — для дати, int — для кількості днів.
- Car[] cars — масив автомобілів; cars.Length — кількість записів.
- ShowCars циклом for переносить масив у таблицю та оновлює кількість записів.
- У buttonSearch_Click перевіряється головна умова:

```csharp
if (!cars[i].InTrip && cars[i].Capacity >= cargo)
```

`!InTrip` означає «не в рейсі», `&&` вимагає виконання обох умов,
`>= cargo` означає «вміщує заданий вантаж». Пошук проходить весь масив,
тому показує всі відповідні автомобілі.

- checkBoxTrip_CheckedChanged вмикає або вимикає поля рейсу.
- buttonAdd_Click створює Car із введених значень. Array.Resize збільшує
  масив на один елемент, нова машина записується в останню позицію.
- buttonSave_Click відкриває SaveFileDialog, а StreamWriter записує весь масив.
  using закриває файл, try/catch показує повідомлення про помилку запису.
- Form1.Designer.cs містить елементи форми та підключення подій.
  Form1.cs містить поведінку програми, Program.cs запускає вікно.

## Перевірка

У хмарному середовищі перевірено файли проєкту та ресурсів, підключення подій,
сім полів, десять записів і очікувані вибірки початкових даних.
C#/.NET Framework і Windows Forms тут відсутні: збірка й запуск не виконані.

Після збірки перевірте на Windows:

- Спочатку таблиця містить 10 машин, із них 7 вільні.
- Вантаж 3,5 т — 5 результатів, 4 т — 3 результати, 10 т — лише Volvo FL.
- Вантаж 12 т — немає результатів: Scania P має потрібну місткість, але в рейсі.
- Вантаж 1000 т — немає результатів. Рівно 3,5 т не виключає Iveco та Hyundai.
- Додавання вільної машини і машини в рейсі, заборону повторного номера,
  порожніх полів, від’ємної або нульової маси.
- Після додавання кількість зростає, а файл містить заголовок та всі записи.
- Скасування діалогу збереження не змінює дані.
